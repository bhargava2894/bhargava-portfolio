# Bhargava Sista - 3D Portfolio

A high-end, professional 3D portfolio website built with React, Three.js, and Framer Motion.

## Features

- **3D Hero Section**: Interactive abstract 3D scene with React Three Fiber
- **Dark Blue Theme**: Professional dark theme with accessible contrast
- **Responsive Design**: Optimized for desktop and mobile devices
- **Performance Optimized**: Lazy loading, code splitting, and efficient 3D rendering
- **Modern Tech Stack**: React, Vite, Three.js, Framer Motion
